# Ubuntu AI System Administrator

> [!WARNING]
> This is under development.

> [!IMPORTANT]
> Installs a private, root-capable AI Systems Administrator
> account with a loopback-only chat service, an explicit approval gate, and an
> auditable command log. This repository exists only to install, verify, repair,
> and remove AI Agent.

> [!NOTE]
> Start with [`docs/QUICKSTART.md`](docs/QUICKSTART.md). Read
> [`SECURITY.md`](SECURITY.md) before installing because compromise of the agent
> account or provider credentials is equivalent to root access on the machine.
